GitHub 资源代理

让 GitHub 资源下载更简单。

输入 GitHub 资源链接，生成当前代理地址并直接访问。支持 Release 文件、源码归档、仓库文件和 Gist 原始内容。

访问会在新标签页打开；复制后可将代理地址用于浏览器、脚本或下载工具。

输入示例

点击任意示例，快速开始

短路径写法

owner/repo/releases/download/v1.0.0/file.zip owner/repo/archive/master.zip owner/repo/blob/master/README.md

完整 URL

https://github.com/owner/repo/releases/download/v1.0.0/file.zip https://github.com/owner/repo/archive/master.zip

可代理资源

  • release 文件
  • archive 源码包
  • blob/raw 文件
  • gist 原始文件

适用部署

  • Cloudflare Workers
  • Python 3.11+
  • Gunicorn / 反向代理
